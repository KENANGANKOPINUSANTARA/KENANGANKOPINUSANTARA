KENANGAN KOPI NUSANTARA — V39 4K SHARP VISUALS

This package is a drop-in replacement for the previous website build.

VISUAL PASS
- Active website photography replaced with high-resolution editorial imagery.
- No CSS blur filter is used.
- No backdrop-filter blur is used.
- Main images are rendered at 4K-class dimensions and sharpened with Lanczos + UnsharpMask.
- Journal images: 2400x1600.
- Hero / café / horizontal section images: 3840x2160.
- Origin cards: 2160x2700.
- Seasonal feature: 2160x3240.
- JPG quality 96, 4:4:4 chroma (subsampling 0).

GITHUB
1. Extract this ZIP.
2. Upload the extracted files/folders to the root of the GitHub repository.
3. Keep the `assets/photos` folder structure unchanged.
4. Deploy from the repository root on Vercel.
5. If the browser still shows an older image, hard-refresh (Ctrl+Shift+R) or redeploy.

RUN LOCALLY
Double-click START-V39.bat.
