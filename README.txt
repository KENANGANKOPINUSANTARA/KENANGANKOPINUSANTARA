KENANGAN KOPI NUSANTARA — SUMATERA COFFEE COLLECTION
========================================================

Versi ini adalah halaman website mandiri yang sudah dicoding dan siap
di-upload ke GitHub lalu di-deploy ke Vercel.

Produk Sumatera yang dimasukkan:
1. Aceh Gayo Bourbon — Rp95.000 / 100g
2. Aceh Gayo Natural — Rp90.000 / 100g
3. Aceh Gayo Wine — Rp110.000 / 100g
4. Mandheling — Rp90.000 / 100g
5. Lintong — Rp90.000 / 100g
6. Kerinci — Rp90.000 / 100g
7. Kerinci Mossto — Rp130.000 / 100g (Seasonal)

FILE:
- index.html
- styles.css
- README.txt

DEPLOY GITHUB:
1. Extract ZIP.
2. Upload ketiga file ke repository.
3. Commit & push.

VERCEL:
1. Import repository tersebut ke Vercel.
2. Framework: Other / static.
3. Build command: kosong.
4. Output directory: .
5. Deploy.

CATATAN:
- Halaman ini tidak memakai backend.
- Packaging dibuat sebagai CSS/HTML sehingga tidak bergantung pada file gambar
  eksternal dan tidak akan mengalami broken image.
- Data produk diambil dari data koleksi Sumatera yang sudah ada di project.
